\section{Formal verification}\label{sec:verification}

The proof of Theorem~\ref{thm:main} is formalized in Lean 4.34.1,
using mathlib and the OpenAI formal library \cite{OAIpi}.
The approximation theorem and its irrationality-exponent corollary
are in the module \texttt{LogRatioMain.lean}.

The formalization includes the local comparison, curve inequality,
interpolation theorem, determinant estimates, and parameter construction.
Its dependency closure was replayed in an initially empty Lean kernel
environment, with only \texttt{propext}, \texttt{Classical.choice}, and
\texttt{Quot.sound} permitted as axioms. The source supplement records
the pinned dependencies, theorem-to-section correspondence, and
commands for reproducing the verification.
